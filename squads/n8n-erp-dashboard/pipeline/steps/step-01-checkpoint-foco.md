## Pergunta 1: Quais relatórios coletar?

Os relatórios disponíveis na API Dapic são:

1. **Todos os relatórios** — Vendas + Estoque + Contas a Pagar + Contas a Receber (recomendado)
2. **Apenas Vendas e Estoque** — foco operacional
3. **Apenas Contas a Pagar e Receber** — foco financeiro
4. **Personalizado** — especifique quais relatórios deseja

## Pergunta 2: Qual período de dados históricos para o dashboard?

1. **Últimos 30 dias** — padrão, boa cobertura para análise mensal
2. **Últimos 90 dias** — visão trimestral completa
3. **Últimos 7 dias** — foco em análise semanal recente
4. **Personalizado** — especifique o período desejado
